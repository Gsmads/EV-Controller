# ADR-0004: Слоистая модель педалей с настраиваемым комбинатором

**Статус:** принято
**Дата:** 2026-06-11

## Контекст
Первая версия использовала бинарный переключатель источника: либо педали
ребёнка, либо команды по UART. Это не описывает реальный сценарий.

Реальный сценарий такой. Ребёнок едет, нажав газ примерно наполовину.
Родитель хочет притормозить — жмёт тормоз в приложении. Машина замедляется.
Родитель отпускает — и ребёнок должен продолжить движение с той скоростью,
на которую нажата **его** педаль, а не остановиться и не ждать команды.
Так работают машинки в игровом центре: рулит ребёнок, у оператора есть
возможность вмешаться.

При бинарном переключателе отпускание виртуальной педали означало бы
резкую передачу управления, а забытое переключение — что физическая
педаль не действует вовсе.

## Решение
У каждой педали два независимых значения: `physical` из АЦП и `uart`
из команд. Эффективное значение вычисляется комбинатором:

```
effective = combine(physical, uart)
```

Комбинатор задаётся настройкой раздельно для газа и тормоза. По умолчанию
`MAX` — действует то воздействие, которое сильнее. Доступны также
`ADDITIVE_CLAMP`, `UART_PRIORITY`, `PHYSICAL_ONLY`, `UART_ONLY`.

Виртуальные педали имеют собственный watchdog: если команда не приходит
дольше заданного времени, значение снимается.

## Последствия
- Сценарий вмешательства работает естественно, без переключений режимов.
- Физическая педаль никогда не отключается — ребёнок не остаётся
  без управления из-за состояния программы.
- Поведение меняется настройкой, а не перекомпиляцией.
- Требуется аккуратность с watchdog: снятие газа при потере команд
  безопасно, снятие тормоза — нет. См. ADR-0006.
- Телеметрия должна показывать все три величины (`physical`, `uart`,
  `effective`), иначе поведение станет непонятным при отладке.

## Отклонённые варианты
| Вариант | Почему отклонён |
|---|---|
| Бинарный переключатель источника | Не описывает сценарий вмешательства; забытое переключение отключает педаль ребёнка |
| Только сложение | Родитель не может ограничить ребёнка, только добавить |
| Жёсткий приоритет UART | Требует постоянной отправки команд, иначе управление теряется |
| Комбинатор зашит в код | Подобрать поведение можно только опытом на площадке, значит нужна настройка |

## Проверка
Тесты на все пять комбинаторов, на watchdog каждой педали отдельно
и на приоритет тормоза над газом. Телеметрия содержит все три величины.
