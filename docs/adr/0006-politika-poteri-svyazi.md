# ADR-0006: Три таймаута вместо одного, политика потери связи настраивается

**Статус:** предложено
**Дата:** 2026-09-09

## Контекст
Техническое задание (§6.5) описывает потерю связи как одно событие:
нет команд — переходим в fail-safe и останавливаемся.

Владелец указал, что для этого проекта такое поведение неверно.
Родитель подключается к машине с телефона эпизодически. Дети катаются
на даче, когда никто не подключён. Остановка при отсутствии связи
означала бы, что машина не едет большую часть времени.

При этом система состоит из двух блоков, и «потеря связи» означает
три разных события с разными последствиями.

## Решение
Различать три события и обрабатывать их раздельно.

| Событие | Смысл | Обработка |
|---|---|---|
| Команда не повторилась (около 200 мс) | пакет потерялся, линия жива | газ снимается, тормоз удерживает последнее значение |
| Телефон отключился от ESP32 (WiFi) | **штатная ситуация** | политика настраивается, по умолчанию снять виртуальные педали |
| ESP32 не отвечает Arduino (RS485) | **неисправность внутри машины** | политика настраивается, по умолчанию ограничить режимом Eco |

Политики: `IGNORE`, `RELEASE_VIRTUAL`, `LIMIT_ECO`, `STOP`.
Отдельная настройка `brake_on_link_lost`: удерживать или снимать.

Веб-клиент отправляет явное снятие управления при закрытии вкладки —
это убирает большинство случаев «залипшего тормоза».

## Последствия
- Поведение соответствует реальному использованию, а не абстрактной
  модели «связь обязана быть».
- Появляется промежуточная политика `LIMIT_ECO`: машина продолжает
  ехать, но с ограничениями. Ребёнок не остаётся посреди участка,
  и при этом не гоняет без присмотра при неисправности.
- Асимметрия газа и тормоза становится явной: снятие газа при потере
  команд безопасно, снятие тормоза опасно.
- Три политики вместо одной — больше состояний для проверки.
- Требуется различать «пакет потерялся» и «линия мертва», то есть
  отдельный счётчик тишины на линии, а не только на командах.

## Отклонённые варианты
| Вариант | Почему отклонён |
|---|---|
| Одно правило «нет связи — стоп» (как в ТЗ) | Машина не поедет, когда родитель не подключён; это основной режим использования |
| Одна галочка на всё | Смешивает штатное отключение телефона и отказ шлейфа внутри машины |
| Симметричный watchdog на газ и тормоз | Снятие тормоза при потере связи — отказ в опасную сторону |

## Проверка
Сценарные тесты: обрыв WiFi при нажатом виртуальном тормозе; обрыв
RS485 на ходу; потеря отдельного пакета при удерживаемом тормозе.
Для каждого — ожидаемое поведение зафиксировано заранее.
