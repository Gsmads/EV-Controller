# Архитектурные решения (ADR)

Записи решений, которые дороже отменить, чем принять. Формат и правила —
`../CONVENTIONS.md` §4. Шаблон — `0000-template.md`.

ADR не редактируются после принятия. Изменение решения оформляется новым
ADR со ссылкой «заменяет ADR-NNNN».
