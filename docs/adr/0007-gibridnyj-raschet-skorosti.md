# ADR-0007: Гибридный расчёт скорости — счёт импульсов и измерение периода

**Статус:** предложено
**Дата:** 2026-09-09

## Контекст
Скорость считается по импульсам с датчиков мотор-колёс. Число импульсов
на оборот определяется драйвером ZS-X11H и равно утроенному числу пар
полюсов — ожидается 30–70.

При 45 импульсах на оборот и колесе 255 мм скорость 1 км/ч даёт около
15 импульсов в секунду. За окно 100 мс это один-два импульса, то есть
дискретность порядка 0,5 км/ч.

Именно на малой скорости эта величина важнее всего: на циферблате
сравниваются дуги скорости и ШИМ, и разница между ними показывает
нагрузку. На трогании с места, где нагрузка максимальна, показания
прыгали бы ступенями.

## Решение
Два метода в одном модуле с автоматическим переключением:

| Условие | Метод |
|---|---|
| импульсов за окно больше порога | подсчёт за фиксированное окно |
| импульсов мало | измерение периода между импульсами |
| импульсов нет дольше таймаута | скорость равна нулю |

Порог переключения и таймаут — настраиваемые параметры.

## Последствия
- Разрешение сохраняется во всём рабочем диапазоне.
- Явное обнуление по таймауту: без него последнее значение «залипает»
  после остановки, и машина показывает движение, стоя на месте.
- Усложняется ISR: помимо счётчика нужна метка времени последнего
  импульса.
- Появляется переходная зона возле порога, где метод меняется;
  нужно сглаживание, иначе показания дёрнутся при переключении.

## Отклонённые варианты
| Вариант | Почему отклонён |
|---|---|
| Только подсчёт за окно | Непригоден на малой скорости — там, где показания нужнее всего |
| Только измерение периода | На высокой скорости частота прерываний растёт, а шум одиночного периода выше |
| Удлинить окно до 500 мс | Задержка становится заметной; дуга скорости отстаёт от реальности |

## Проверка
Тест с синтетическим потоком импульсов: заданная частота на входе,
ожидаемая скорость на выходе, для трёх точек — низкой, пороговой
и высокой. Отдельная проверка обнуления по таймауту.
