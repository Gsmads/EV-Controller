# ADR-0009: Аналоговые каналы настраиваются в рантайме, цифровые функции — нет

**Статус:** принято
**Дата:** 2026-09-09

## Контекст
Соответствие сигналов аналоговым входам определяется кабельной разводкой
между платой аналоговых входов и платой микроконтроллера. По схеме оно
не восстанавливается, а при монтаже провода удобно переставить местами.

Владелец предложил принять карту разъёмов условной и уточнять
соответствие из веб-интерфейса.

## Решение
Разделить распиновку на две категории.

**Настраивается в рантайме** — номера каналов АЦП для газа, тормоза,
трёх датчиков тока и положения руля. Это просто индексы, любой сигнал
читается с любого входа. Переезжают из `cfg_board.h` в настройки,
попадают в реестр параметров, валидируются: номер меньше восьми,
два сигнала не на одном канале.

**Остаётся в `cfg_board.h`** — всё, что привязано к аппаратуре:

| Функция | Почему нельзя переназначить |
|---|---|
| ШИМ моторов | только выводы сравнения Timer1 |
| Энкодеры колёс | только входы внешних прерываний |
| I²C | аппаратный модуль привязан к конкретным выводам |
| SPI | то же |
| ШИМ руля | вывод сравнения Timer0 |

## Последствия
- Ошибка монтажа исправляется настройкой, а не паяльником.
- Правило простое и запоминающееся: аналоговое настраивается,
  цифровое нет.
- Требуется валидация: два сигнала на одном канале означали бы, что
  педаль газа читает ток мотора.
- Смена канала на ходу должна быть запрещена при движении —
  флаг `REQUIRES_STOP` в реестре параметров.

## Отклонённые варианты
| Вариант | Почему отклонён |
|---|---|
| Всё жёстко в коде | Любая перестановка провода требует перепрошивки |
| Настраивать и цифровые выводы тоже | Физически невозможно: аппаратные модули привязаны к выводам |

## Проверка
Тест: попытка назначить два сигнала на один канал отклоняется.
Тест: назначение канала больше семи отклоняется.
